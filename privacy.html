JS STUDIO 개인정보처리방침

시행일: 2026년 11월 4일 · 최종 수정: 2026년 11월 4일

1. 서비스 소개

JS STUDIO는 운영자가 직접 제작·관리하는 유튜브 쇼츠 영상을 정리하고, 운영자 본인의 유튜브 채널에 예약 업로드하기 위한 내부용 관리 도구입니다. 일반 사용자에게 공개된 서비스가 아닙니다.

2. 사용하는 Google 데이터와 목적

  • Google Drive: 운영자의 드라이브에 저장된 영상 파일을 읽어, 업로드할 영상을 가져오는 데만 사용합니다.
  • Google Sheets: 영상 목록, 예약 시간, 업로드 결과를 운영자 소유의 스프레드시트에 기록합니다.
  • YouTube: 운영자 본인 채널에 영상을 업로드하고 공개 시간을 예약하며, 업로드한 영상의 공개 조회수를 확인합니다.

3. 데이터의 보관

모든 데이터는 운영자 소유의 Google 계정(드라이브·스프레드시트·유튜브 채널) 안에만 보관됩니다. JS STUDIO는 별도의 외부 서버나 데이터베이스에 데이터를 저장하지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 광고 목적이나 다른 서비스의 학습 목적으로 사용하지 않습니다.

5. 권한 철회

Google 보안 설정의 타사 앱 액세스 관리 페이지에서 언제든지 JS STUDIO의 접근 권한을 삭제할 수 있습니다. 권한을 삭제하면 이후 어떤 데이터에도 접근하지 않습니다. 시트에 기록된 데이터는 운영자가 스프레드시트에서 직접 삭제할 수 있습니다.

6. YouTube API 서비스 사용과 약관

JS STUDIO는 YouTube API 서비스를 사용합니다. JS STUDIO를 사용하면 YouTube 서비스 약관에 동의하고 이를 따르는 것으로 간주됩니다. YouTube 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

JS STUDIO가 Google API로 받은 정보의 사용은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

JS STUDIO uses YouTube API Services. By using JS STUDIO, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. You can revoke access at security.google.com/settings/security/permissions.
