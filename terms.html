JS STUDIO는 운영자가 직접 제작·관리하는 유튜브 쇼츠 영상을 정리하고, 운영자 본인의 유튜브 채널에 업로드·예약하기 위한 내부용 관리 도구입니다. 일반 사용자에게 판매하거나 공개하는 서비스가 아닙니다.

JS STUDIO는 YouTube API 서비스를 사용합니다. JS STUDIO를 사용하는 사람은 YouTube 서비스 약관에 동의하고 이를 따라야 합니다. YouTube 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

업로드 버튼을 누르는 사람은 올리는 콘텐츠가 YouTube 서비스 약관과 커뮤니티 가이드를 준수하며, 다른 사람의 저작권이나 개인정보 권리를 침해하지 않음을 확인합니다. 제목, 설명, 공개 범위, 아동용 여부, 공개 시간은 사용자가 직접 정합니다.

JS STUDIO가 Google 데이터를 다루는 방식은 JS STUDIO 개인정보처리방침을 따릅니다. 접근 권한은 Google 보안 설정에서 언제든지 삭제할 수 있습니다.
